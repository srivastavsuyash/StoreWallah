## 📖 About the Project

**STOREWALLAH** is a frontend e-commerce web application that provides a clean and interactive shopping experience. It includes sections like Hero banners, product listings, testimonials, popups, and more — all built as reusable React components.

---

## ✨ Features

- 🏠 **Hero Section** — Eye-catching landing banner
- 🛒 **Products Listing** — Browse available products
- 🌟 **Top Products** — Highlighted/featured items
- 💬 **Testimonials** — Customer reviews section
- 📢 **Banner** — Promotional banners
- 🔔 **Popup** — Interactive popup component
- 📧 **Subscribe** — Newsletter subscription section
- 🔝 **Navbar** — Responsive navigation bar
- 🔻 **Footer** — Site footer with links
- 📱 **Fully Responsive** — Works on all screen sizes

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) (v16 or above)
- [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)

---

## 📦 Installation

1. **Clone the repository**

```bash
git clone https://github.com/your-username/storewallah.git
```

2. **Navigate to the project folder**

```bash
cd storewallah
```

3. **Install dependencies**

```bash
npm install
```

---

## ▶️ Running the Project

Start the development server:

```bash
npm run dev
```

Open your browser and go to:

```
http://localhost:5173
```

---

## 🏗️ Build for Production

To create an optimized production build:

```bash
npm run build
```

The output will be in the `dist/` folder.

To preview the production build locally:

```bash
npm run preview
```

---

## 🌐 Deploy on Vercel

### Option 1: Drag & Drop (Easiest)

1. Run `npm run build` to generate the `dist/` folder
2. Go to [vercel.com](https://vercel.com) and log in
3. Drag and drop the `dist/` folder on the Vercel dashboard
4. Your site is live! 🎉

### Option 2: GitHub Integration (Recommended)

1. Push your code to GitHub
2. Go to [vercel.com](https://vercel.com) → **New Project**
3. Import your GitHub repository
4. Set the following settings:
   - **Framework Preset**: Vite
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
5. Click **Deploy** — Done! ✅
